Start with recurring cost

Read the switch conditions

CASS, Direct Debits, deposits and card payments can all be required.

Separate cashback from bonus

Ongoing cashback should not be compared as if it were immediate cash.

Check overdraft pricing

A free current account can still be expensive if you regularly use an overdraft.
