Cookie & Storage Policy

Last updated: 12 August 2026

Effective date: 12 August 2026.

The current BankRanking build is a static comparison website and does not intentionally set BankRanking advertising or analytics cookies.

1. Session storage used for translation UI

If your browser language is not English, BankRanking may show a small translation suggestion. If you close it, the site may store a session-only value named br_translate_dismissed so the prompt can remain hidden during that browser session. This storage is used only for the interface preference.

2. External websites and affiliate redirects

When you click a bank, Google Translate or affiliate link, you leave BankRanking or pass through an external service. That external service may use cookies, local storage, device identifiers or similar technologies under its own policy.

3. Google translation

The website does not embed the legacy Google Website Translator widget. The optional “Translate with Google” control opens a Google Translate URL only after the visitor chooses it. Chrome's own built-in translation is controlled by the visitor's browser settings.

4. Future analytics or advertising

If BankRanking later adds non-essential analytics, remarketing, advertising pixels or similar technologies that require consent, the site must add an appropriate consent mechanism and update this policy before those technologies are activated.
